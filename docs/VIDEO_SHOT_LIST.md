# 演示视频录屏清单

成片约 2 分半，共 12 段，每段单独录一个文件，文件名用编号开头（如 `01_首页.mp4`）。
录完放进一个文件夹（如桌面 `录屏素材`），交给 Claude 抽帧看内容、剪辑并写字幕（`.srt`），
再在剪映 / 必剪里导入字幕，用"文本朗读"一键配音。

## 录之前

- **外观**：统一深色或统一浅色，跟 README 截图一致
- **勿扰模式**：打开，别录进通知横幅
- **基建免责声明**：先进一次基建规划，在弹窗里点"不再提示"
- **竖屏录制**；iPhone 录屏不显示手指位置，动作慢一点、清楚一点，字幕会说明点了哪里
  - 用模拟器录的话可以先显示触摸点（运行后重启模拟器）：
    `defaults write com.apple.iphonesimulator ShowSingleTouches 1`
- **每个动作后停顿 1 秒左右**，方便下刀；每段开头、结尾多停 2 秒
- 某个动作点错了不用停止录屏，停 2 秒重新做一遍，剪的时候挑好的那次

## 分段

| 编号 | 内容 | 操作 | 成片时长 |
|---|---|---|---|
| 01 | 首页 | 从手机桌面点开 App → 停在首页 → 慢慢往下滑到"数据概览" → 停住 | 8 秒 |
| 02 | 摆放和画线 | 进入基建规划 → "…" → 切换到**四号谷地小基地** → 点"建造" → 长按一台**精炼炉**拖进画布 → 在上边放一个**取货口** → 切到"传送带"，从取货口拖一条线到精炼炉 → 点精炼炉打开详情，选一个配方 | 20 秒 |
| 03 | 加载预设 | "…" → 加载**武陵预设** → 确认 → 停在自动缩小、居中的全图 | 10 秒 |
| 04 | 缩放浏览 | 双指放大到右侧气体链和**水泵区** → 停一下，让产物图标和分流器符号露出来 → 单指拖动看一圈 | 15 秒 |
| 05 | 机器详情 | 点一台**固气转化机** → 停在详情面板（配方、状态、进出流量） → 关闭 | 10 秒 |
| 06 | 产能统计和高亮 | 点右下角"统计" → 慢慢往下滑 → 点"**重息壤**" → 画布高亮 → 稍微放大看亮着的线 → 点顶部提示条的 × 取消 | 20 秒 |
| 07 | 利用率 | 点"线的利用率" → 停 2 秒 → 放大到一段带百分比的线 → 再点一次关掉 | 10 秒 |
| 08 | 导出图片 | "…" → "导出布局图片" → 停在分享面板 → 点"存储图像" | 8 秒 |
| 09 | 产量计算 | 回首页 → "产量计算" → 选产物，搜"**灼铜装备原件**" → 点快捷按钮 **6** → 往下滑看生产步骤 → 某一行点 ⋯ → "**改成从仓库取**" → 停在台数变化后的结果 | 30 秒 |
| 10 | 配方分析 | 回首页 → "配方分析" → 搜**灼铜块** → 打开配方树 → 双指缩放看一下 | 15 秒 |
| 11 | 社区蓝图 | 回首页 → "社区蓝图" → 点一套蓝图集 → 往下滑 → 点"**复制分享码**" | 15 秒 |
| 12 | 结尾 | 回首页 → 右上角设置 → 点 "Report Issue" → 停在两个选项上 → 取消 | 8 秒 |

合计约 2 分 40 秒，剪掉停顿后在 2 分半左右。

- 表里是成片时长，原始素材多录几秒没关系
