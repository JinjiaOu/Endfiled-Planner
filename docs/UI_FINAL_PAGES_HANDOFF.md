- 保留搜索前缀优先 / 包含匹配、联想补全文字、全部物品菜单、最近搜索、单条删除 / 全部清除历史、空搜索与无结果提示。历史管理实现、持久化键和最多 8 条的规则未改。

- 原保存图片、相册写入、分享、结果提示与导出尺寸行为保留；节点同步新样式，并传入当前颜色模式。清单模式中的保存 / 分享明确标注为配方树图片，导出的仍是原图形树。导出未作运行验证。
