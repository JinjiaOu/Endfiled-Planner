## 1. 实际改变了什么

### 工作区布局

- 顶部改成地图与当前编辑模式，并独立放置撤销、重做、保存入口。更多菜单中的保存、切换地图、两套预设与清空继续保留。
- 原来挤在顶部一行的编辑工具移到底部，普通字号按宽度换行；无障碍大字号使用可横向滚动的完整工具按钮。选择、建造、传送带、管道、框选、我的布局、删除均保持可访问；四号谷地仍遵循原地图规则不展示管道。
- 删除模式有明确文字提示；不改变删除工具、撤销分组或确认规则。
- 手机属性 / 建造区按可用高度限制，内容可滚动，尽量为画布留出空间。宽屏只有实际宽度至少 900pt、高度至少 520pt 且 regular size class 时才使用侧面板。
- 侧面板边距参考顶部工作区和底部工具区的实际高度，浮动统计入口也预留侧面板空间。

### 画布视觉

- 采用中性深色底板与灰色细网格，减轻原来的全黄网格干扰。
- 建筑采用中性底面、低强度分类填充和分类图标；黄色选中边框、青色框选、冲突、端口、方向、线路与利用率的语义继续保留。
- 二维画布始终保持深色，周边控件使用 Phase 2 的动态深浅色 Token。
- 保留线的方向动画，开启系统 Reduce Motion 后停止该动画。
- 建筑增加无障碍名称、状态和选择操作；网格内文字仍按缩放比例绘制，完整名称与可读详情在检查面板中呈现，不能将此理解为所有网格文字都已随 Dynamic Type 排版。

### 建筑、线路及组操作

- 建筑与线路接入统一的非模态检查容器，具有标题、状态、关闭、折叠、详情和动作区。没有改成会阻断画布操作的模态 Sheet。
- 手机高度受限时整个面板可滚动；操作区位于标题后，折叠详情仍保留操作入口。侧面板则维持独立内容滚动。
- 建筑的开关、移动 / 取消移动、旋转、收纳，以及各专用配置继续调用原方法；配方、反应池多选、激活、物料、限速与过滤、核心端口、燃料、供电范围等原内容分支保留。
- 到货 / 需求、实际产出、激活数据改用可换行的名称 / 数值行；没有修改计算公式、单位换算或精度口径。
- 修正旧移动提示中“原来接的线不会跟着走”的过时文案，说明现有线路会尝试重接，无法连接时提示。
- 线路详情保留长度、上限、流量、状态、连接与货物；保留删一格、删整条及整条删除确认。
- 框选和布局放置统一外观，保留存为布局、整组删除、取消、旋转与确认放置，以及原禁用条件。

### 统计与反馈

- 统计按“摘要 → 运行诊断 → 电力与物流 → 产出 / 消耗 → 建筑分类”分区。
- 保留建筑数、产线数、发电、耗电、余量、瓶颈、直通节点、仓库物料、未通电、未收敛、异常设备、终点消耗、分类、全部产出与消耗行。
- 告警和说明不再通过固定三行裁切；采用完整换行。
- 统计浮层按当前可用宽高布局，提供明确关闭按钮；保存提示与利用率入口采用统一组件，移除原有光晕。
- 没有添加虚构趋势图、预测指标或新的模拟结果。

## 3. 用户运行时优先查看

以下仅供用户验证，代理没有执行：

1. 进入基建，确认顶部撤销 / 重做 / 保存和底部全部工具清楚可见，双地图的工具差异正确。
2. 建造、拉线、选择、移动、旋转、框选、删除，再撤销 / 重做，重点观察工具栏换位后拖拽与边缘自动滚动的位置是否准确。
3. 打开建筑与管线面板，折叠 / 关闭，滚动专用配置并修改配方；确认画布仍可操作。
4. 打开我的布局，保存组、跨地图放置、旋转、查看阻挡原因、取消或确认，核对与旧行为一致。
5. 打开统计，查看长名称、全部告警及消耗明细；和旧版同一布局的数值比较。
6. 在小屏 / 横屏、大字号和 iPad 分屏查看面板高度、侧栏避让、关闭按钮与建造卡片长名称；再按需查看 VoiceOver 和 Reduce Motion。

## 5. 首轮截图反馈后的收紧调整

用户提供 IMG_2909.PNG，指出底部占用过大、视觉廉价。截图确认首版工具栏出现第二行，建造区的胶囊、边框与独立旋转栏过重，利用率图例和两个大按钮又覆盖了画布。

- 分类由大胶囊改成文字标签与细选中线；设施由 52pt 带框图标改成较小分类图标、完整名称与尺寸。
- 旋转与关闭并入建造区标题行，移除独立底部旋转 / 提示栏。
- 利用率和统计合并为一条轻量浮动控制条；图例通过信息按钮按需打开，保持原有四种利用率说明可访问。

这轮没有运行、测试或生成截图；实际占用与视觉效果继续交由用户确认。先前段落描述的是首轮实现，本节为其后续调整。
