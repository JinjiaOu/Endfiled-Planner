### 工作台

首页从带装饰横幅的功能展示页调整为紧凑任务页：

- 简短产品标题与用途说明。
- 基建规划、配方分析、社区蓝图三个明确入口，放在同一个轻量分组中。
- 继续展示真实数据更新横幅、下载进度和待重启状态。
- 保留配方、产物、设备三个统计；保持旧计数方式，注明多产物配方会按不同产物分别计入。
- 采用语义字号，普通字号三个数值并排，无障碍大字号纵向排列。
- 移除重复英文大标题、恒定 ONLINE / READY、装饰网格、彩色卡片边框与巨大的功能图标。
- 设置仍从齿轮进入，保留更新标记；以原生 Sheet 展示，并补充明确的“完成”关闭入口。

### 平级导航

- 原生四标签：工作台 / 配方 / 蓝图 / 基建。
- 工作台的任务入口切换到相应标签，避免同一模块经多个 NavigationLink 创建不同实例。
- 各模块沿用自己的 NavigationStack；不再在模块外叠加一个总 NavigationStack。
- 各标签的视图结构保持稳定，不用 `if selected...` 或 `.id(selected...)` 重建编辑器；保留内存中的布局、选择、缩放和撤销状态是该导航实现的目标，需由用户实际切换验证。
- 基建编辑时隐藏全局标签栏，并在左上角提供“工作台”返回入口。退出只切换标签，不调用清空、重载或自动保存。
- 基建免责声明通过独立进入标记延续原“每次进入提示，选择不再提示后停止”的规则。该标记只传给免责声明，不作为 SwiftUI View identity，也不修改原持久化键。
